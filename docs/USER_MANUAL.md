# S3D Equipment Part Array 用户手册

适用版本：v0.1.0。此工具在 Hexagon Smart 3D 中对同一台设备下的部件或形体生成独立副本，原件保留原位。面板同时显示中文和英文，启动时默认环形阵列，并保持窗口置顶。

## 1. 安装与启动

1. 关闭 Smart 3D，解压发布包中的 `S3D_EquipmentPartArray` 文件夹，将其中的 `S3D.EquipmentPartArray.dll` 和 `YYB.Licensing.dll` 放入命令文件夹。更新时同时替换旧 DLL，随后重新启动 Smart 3D。
2. 在 Smart 3D 自定义命令配置中，程序集使用 `S3D_EquipmentPartArray\S3D.EquipmentPartArray`，类名使用 `S3D.EquipmentPartArray.EquipmentPartArrayCommand`。命令文件夹与程序集配置的相对路径须一致。
3. 可先选对象再启动命令，也可先启动命令再选对象。若宿主报告“Class ... not found”，先核对类名、DLL 路径和依赖库，再重启客户端。

> 安装位置和注册入口取决于现场 Smart 3D 配置。本包没有安装程序，也不会自动修改宿主配置。

## 2. 选择源对象

1. 在模型视图或工作区浏览器中选择一个或多个源对象。可在命令启动后使用框选。
2. 点击 **使用所选部件/形体 / Use selection**，确认顶部 **源对象 / Sources** 显示预期数量。预选对象存在时，命令会尝试自动获取。
3. 全部源对象必须属于同一台设备。支持 `EquipmentComponent`，以及直接属于 `Equipment` 的 `GenericShape`。点选部件下的 `GenericShape` 或 `PrismaticShape` 时，工具把其父级 `EquipmentComponent` 作为源对象；同一部件下选中多个形体只算一个源对象。

设备本体、设备直属 `PrismaticShape`、管口和端口不能作为源对象。源对象需要读取和编辑权限，所属设备需要创建权限。选择不符合要求时，面板底部会显示原因。

## 3. 环形阵列（默认）

1. 在 **模式 / Mode** 选择 **环形 / Circular**。
2. 设置 **中心 / Center X、Y、Z**，或点击 **拾取中心 / Pick center** 后在模型视图点选中心。
3. 设置 **轴向 / Axis X、Y、Z**，或点击 **拾取旋转轴 / Pick axis (2 pts)**，在模型视图依次点选两点。旋转轴经过中心点，方向由轴向量或两点顺序确定。轴向不能为零。
4. 设置 **环形数量 / Count** 和 **填充角 / Fill angle**。数量包含原始源对象组，填充角单位为度，范围为大于 0° 且不超过 360°。
5. 按需勾选 **副本随阵列旋转 / Rotate copies**。勾选时副本位置和自身朝向一起旋转；取消时仅旋转位置，保留源对象朝向。

例如，选中 1 个形体，数量设为 4、填充角设为 360°，会新增 3 个副本，四组位置每隔 90°。填充角设为 180° 时，四组位置位于 0°、60°、120°、180°。多选时，每个角度放置整组对象，保持组内相对位置；若源对象恰在旋转轴上，其位置不会随角度移动。

## 4. 矩形阵列

1. 将 **模式 / Mode** 切换为 **矩形 / Rectangular**。
2. 在 **方向 / Directions** 选择 **全局 / Global** 或 **设备局部 / Equipment local**。列、行、层分别沿所选坐标系的 X、Y、Z 方向。
3. 设置 **行数 / Rows**、**列数 / Columns**、**层数 / Layers** 和对应间距 **Row pitch**、**Column pitch**、**Layer pitch**。数量均包含原始组。距离可按 Smart 3D 当前单位格式输入，例如 `500 mm`。

例如，选中 2 个部件，设置 2 行、2 列、1 层，会新增 `(2×2×1−1)×2 = 6` 个独立副本。原始组位于第 0 行、第 0 列、第 0 层，保持原位。负间距可用于反向排布。

**基点 / Base X、Y、Z** 与 **拾取基点 / Pick base** 当前仅记录参考点；矩形阵列的实际偏移仍以各源对象原位置和间距计算，修改基点不会移动阵列起点。

## 5. 预览、创建与取消

- 修改参数后，面板底部显示 **预计新增 / Additional items**。模型中用黄色短线标记预计副本原点；这是位置预览，不是完整形体预览。预览对象不会正式保存到模型。
- 确认源对象、数量、方向和位置后点击 **创建 / Create**。成功后副本作为独立对象归属源设备，原件保持原位；命名由 Smart 3D 规则处理。
- 关闭窗口、按 Esc 或在模型视图右键可结束命令。创建阶段报错时，工具会中止本次事务；若回滚本身报错，会明确提示先检查模型。
- 一次最多新增 10,000 个对象；这个限制按“新增组数 × 每组源对象数”计算。

## 6. 当前范围与核验

第一版不复制管口、端口或外部连接关系。`GenericShape` 通过同一目录 `Part` 新建，并尝试复制可写、非复杂的 `IJUA*` 实例属性；这不是无条件完整克隆。创建后应在测试模型中核对尺寸、朝向、父设备、名称和关联关系，尤其是带管口或特殊自定义属性的形体。

本项目的本地构建、阵列计算测试和面板测试不能代替 Smart 3D 宿主验收。发布前尚未在本工作区完成新创建路径的宿主验证。建议先在可回退的测试模型中分别试用单选、多选、两种阵列和失败回滚，再用于正式模型。
