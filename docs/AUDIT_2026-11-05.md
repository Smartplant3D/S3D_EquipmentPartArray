# Equipment Part Array audit — 2026-11-05

## Confirmed defects corrected

- The panel placed selection and Create actions inside a long scrolling parameter list. A WinForms visibility test reproduced the selection button being outside the visible panel. Both actions and the mode selector are now fixed; only parameters scroll, with mode-specific fields.
- Distance fields parsed as raw `double`, bypassing Smart 3D project units. The panel now receives `UOMMgr.ParseUnit` and `FormatUnit` for distances. Axis components and fill angle remain numeric.
- Setting one picked point changed three text boxes and triggered repeated preview rebuilds. A test reproduced this; one `SetPoint` now emits one change event.
- Preview code aborted the client transaction even when no temporary preview geometry existed. Abort is now limited to actual preview cleanup or failed creation.
- A UI error after `Commit` could have been reported as a creation failure and rollback. Success UI and command shutdown now run after the creation exception boundary. A failed rollback is reported separately.
- The packaging script previously copied whatever Release DLL was present. It now builds Release before checking entry metadata and packaging.

## Local evidence

`Test-SelectionStartup.ps1`, `Test-CommandEntry.ps1`, `Test-LicenseIntegration.ps1`, `Test-ObfuscationContract.ps1`, 8 placement checks, panel visibility/unit/event checks, and Debug/Release builds passed locally. The obfuscated command entry name and COM attributes were checked in the final DLL.

Verify that step selection captures each type; that temporary preview lines appear and disappear; that copied shapes preserve expected instance dimensions, ownership, orientation and names without unexpected nozzle, port, or external links; that `EquipmentComponentPart` creation still produces the expected component; and that a forced mid-batch failure leaves no copies. The preview is a marker at each planned origin, not a full component ghost. The rectangular base point is currently a reference point and does not change translation offsets.
